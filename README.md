# 🫁 Simple PFM Diary

**Простой дневник пикфлоуметрии** — PWA для ежедневного контроля пиковой скорости выдоха (ПСВ).

Работает полностью **офлайн**, все данные хранятся **локально на устройстве**.

## ✨ Возможности

- **4 измерения в день**: утро (до / после ингаляции) и вечер (до / после ингаляции)
- **3-зонная система** (зелёная / жёлтая / красная) на основе личного лучшего результата
- **Напоминания** через 30 минут после измерения «до ингаляции»
- **График** ПСВ за 7 / 14 / 30 дней с цветовыми зонами
- **Экспорт в CSV** для передачи врачу
- **PWA** — можно установить на смартфон как приложение
- **Быстрый ввод** с кнопками ±10 и автоподстановкой последнего значения

## 🚀 Установка

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## 📱 Установка на телефон

1. Откройте приложение в браузере Chrome (Android) или Safari (iOS)
2. Android: нажмите «Добавить на главный экран» в меню браузера
3. iOS: нажмите «Поделиться» → «На экран «Домой»»

## 🛠 Технологии

- [Next.js 16](https://nextjs.org/) + TypeScript
- [Tailwind CSS 4](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- [Recharts](https://recharts.org/) для графиков
- localStorage для хранения данных
- PWA (Service Worker + manifest)
